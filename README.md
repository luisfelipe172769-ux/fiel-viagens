# **FielViagens \- Logística de Longa Duração 🌎**

Repositório central do **Projeto de Extensão em Desenvolvimento de Software (2026)** da Universidade Nove de Julho (UNINOVE).

## **📌 Sobre o Projeto**

A **FielViagens** é uma agência especializada em roteiros de viagem prolongados (30 a 180 dias). O nosso diferencial não está apenas no destino, mas no que fica para trás. Através do exclusivo **Protocolo Fiel**, garantimos que a residência e os "ativos biológicos" do cliente (cuidados residenciais e pet-safe oculto) permaneçam seguros e florescendo enquanto ele explora o mundo.

## **🛠️ Tecnologias e Grade Curricular**

Este projeto integra os conhecimentos adquiridos ao longo do semestre:

* **Desenvolvimento para Internet:** Website responsivo construído com HTML5, Tailwind CSS e JavaScript.  
* **Algoritmos e Práticas de Programação:** Sistema de gestão interna desenvolvido em **Linguagem C**, utilizando vetores de *structs* para manipulação de dados em memória.  
* **Modelagem de Banco de Dados:** Estrutura relacional (DER/MER) e scripts SQL para persistência de dados de clientes, destinos e logs de monitoramento.

## **🚀 Como Executar**

### **Web-site**

Basta abrir o ficheiro web-site/index.html em qualquer navegador moderno. A interface utiliza o CDN do Tailwind para estilização em tempo real.

### **Sistema em C**

1. Navegue até a pasta src-c/.  
2. Compile o ficheiro principal: gcc main.c \-o fiel\_system.  
3. Execute: ./fiel\_system.

## **🤫 O Protocolo Fiel (Diferencial)**

O nosso sistema possui uma camada de monitoramento discreta. Embora a interface pareça uma agência de viagens convencional, o backend e os protocolos de segurança foram desenhados para pais de pets e viajantes que necessitam de "presença digital e física" constante na sua origem.

* **Espaço Negativo:** O nosso design esconde simbolismos de cuidado e proteção, visíveis apenas para quem conhece a nossa missão.
